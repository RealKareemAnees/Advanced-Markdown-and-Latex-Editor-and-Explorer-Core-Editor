# All Features

## General

- Exporting to HTML, PDF, and Markdown

## Interface

- Menus for elements
- In-preview live editing
- Manual editing

## Blocks

These are standalone blocks; they are not inline.

### Headers

Headers are important to have sections and subsections, starting from 1 to 6.

### Paragraphs

Just some text.

### Checkboxes

Even though they can be put anywhere, they also have a block representation.

### Quote

This is a piece of wisdom.

### Callout

This is customizable and used to grab the reader's attention to some warning, error, and so on.

### Horizontal Line

A separator.

### Lists

Lists are vertical sets of rows; they are either unordered or ordered.

### Toggle Menu

This is a list but is closed by default.

### Table

2D table.

### Code Block

Syntax-highlighted code block.

### Image

Some image.

### Video

Some video.

### Audio

Some audio.

### HTML

You can also insert an entire block of just HTML. It is all HTML at the end of the day.

### Embedding

This could be a web page, HTML file, PDF file, or Excel document.

### LaTeX

Even though inline LaTeX rendering is supported, there is a dedicated LaTeX block.
