Complete Style Guide

This comprehensive style guide showcases all design elements, components, and typography styles available in the Espresso & Ember markdown editor theme. Every element has been carefully crafted to create a warm, focused writing environment.

This page uses real, accessible resources: images from Lorem Picsum, embedded content from MDN and Wikipedia, and functional LaTeX rendering via KaTeX. All interactive components are fully operational!

Typography System

The typography system features three carefully selected font families: Charter for editorial warmth in headings and quotes, Inter for clean UI readability, and JetBrains Mono for technical content. Body text is set at 18px with a generous 1.8 line-height for optimal readability.

// Example TypeScript code
interface DesignToken {
  name: string;
  value: string;
  category: 'color' | 'spacing' | 'typography';
}

const tokens: DesignToken[] = [
  { name: 'accent-primary', value: '#e67e4d', category: 'color' },
  { name: 'space-4', value: '16px', category: 'spacing' },
  { name: 'font-serif', value: 'Charter', category: 'typography' }
];

function applyTokens(element: HTMLElement, tokens: DesignToken[]) {
  tokens.forEach(token => {
    element.style.setProperty(`--${token.name}`, token.value);
  });
}

Background Layers

The espresso theme uses progressive layering to create depth. Each background level is slightly lighter than the previous, establishing clear visual hierarchy:

  • Body (#1a1614): Deepest layer for main background
  • Card (#252220): Elevated surfaces like sidebar and cards
  • Code (#2d2926): Code blocks and input fields
  • Highlight (#2e2a27): Hover states and emphasis
  • Elevated (#2a2522): Footer and special sections

Text Hierarchy

Four text color tiers ensure proper contrast and readability:

  1. Primary (#f0ede1): Main content text - highest contrast
  2. Secondary (#b8b2a7): Supporting text and icons
  3. Tertiary (#7a7469): Metadata and timestamps
  4. Muted (#5a544c): Disabled states and placeholders

Design Philosophy

This design system is built on four core principles:

1. Minimalism

A clean, distraction-free interface that puts content first. Excessive gradients, glows, and decorative effects have been removed in favor of purposeful design.

2. Consistency

Token-based design ensures predictable spacing (4px base), systematic color hierarchy, and mathematical consistency throughout the interface.

3. Accessibility

  • WCAG-compliant contrast ratios (AA and AAA)
  • Clear focus-visible states for keyboard navigation
  • Semantic HTML structure support
  • Reduced motion preferences respected

4. Performance

Efficient CSS selectors, GPU-accelerated transforms, and minimal complexity ensure smooth performance across devices.

What is the design token system?

▶

Design tokens are the atomic values that define the visual language. They include colors, spacing, typography, shadows, and border radii — all defined as CSS custom properties in :root.

By using tokens instead of hard-coded values, we ensure consistency across every component and make theme updates trivial.

How does the spacing system work?

▶

All spacing uses a 4px base grid. Each step is a multiple of 4, from micro adjustments (4px) to maximum spacing (80px). This mathematical consistency ensures harmonious layouts at every scale.

Can I customize the color palette?

▶

Absolutely! All colors are defined as CSS variables. Simply update the values in the :root block to create an entirely new theme while preserving the structural hierarchy and contrast ratios.

Text Formatting

Highlighting

Highlighted text draws attention to key terms: default accent highlight uses the ember orange, yellow highlight for general emphasis, green highlight for positive annotations, blue highlight for informational notes, and red highlight for critical markers.

Italic

Standard italic text uses the default font, while serif italic text adds an editorial quality with the Charter font family.

Strikethrough

Strikethrough text indicates removed content or deprecated features. The red strikethrough line clearly signals this item is no longer valid.

Underline

Underlined text uses the accent color for a warm, intentional emphasis. This is distinct from links — underlines are decorative while links are interactive.

Combined Formatting

Text can combine multiple styles: bold italic, highlighted bold, underline italic, deleted italic, and even all three at once.
